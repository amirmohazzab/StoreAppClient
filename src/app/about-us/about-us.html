Who We Are

StoreApp is a modern e-commerce application built as a professional portfolio project using ASP.NET Core and Angular.

The goal of this project is to demonstrate real-world software architecture, clean code practices, and scalable application design.

Our Mission

Our mission is to build a clean, maintainable, and scalable e-commerce platform that reflects industry best practices and modern development standards.

Technologies Used

  • Backend: ASP.NET Core, Entity Framework Core, MediatR
  • Frontend: Angular, Bootstrap, RxJS
  • Architecture: Repository Pattern, Generic Repository
  • Authentication: ASP.NET Core Identity
  • Database: SQL Server
